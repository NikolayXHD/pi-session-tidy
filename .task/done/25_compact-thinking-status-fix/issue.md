# 25 — Статус выключенного режима compact-thinking

## Контекст

@NikolayXHD: при `enabled: false` в `compact-thinking.json` в футере остаётся
надпись `💭 off` — мусор: выключенное расширение не должно себя показывать.

Второй вопрос @NikolayXHD: поддержана ли возможность выключить (или включить)
режим для текущей сессии без правки конфига. Проверено по коду: поддержано,
`/compact-thinking on` / `off` переключают режим в памяти сессии и не трогают
конфиг. Править нечего.

## Что сделано

- `formatStatusText` (src/logic.ts) возвращает `undefined` вместо `💭 off`;
  `updateStatus` (src/index.ts) убирает статус через
  `setStatus(key, undefined)`. Выключенный режим не показывает статус ни по
  конфигу, ни по команде — мусор `off` исчез в обоих случаях.
- Пробник (src/probe.mjs) больше не ищет jiti по пути раскладки pi из старых
  установок (`~/.pi/node_modules`): правила грузятся нативным type stripping
  в Node, `package.json` получил `"type": "module"`.

## Установка

@pi-agent установил расширение в pi по upstream URL:
`pi install git:github.com/NikolayXHD/pi-compact-thinking`. Правки доходят до
установленной копии только через push и обновление пакета; для отладки кода
удобнее локальная установка из рабочего каталога — вопрос к @NikolayXHD.
