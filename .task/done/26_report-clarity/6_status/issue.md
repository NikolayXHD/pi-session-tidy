# 6 — Счётчик переписанных докладов

Цель: строка статуса показывает результат переписывания докладов.

Способ: короткий счётчик переписанных докладов в строке статуса — рядом с
экономией рассуждений и токенами фоновых вызовов.

Проверка: пробник покрывает формат строки; живая TUI-сессия показывает
счётчик.

## Итог

Сделано @pi-agent: строка статуса получает счётчик переписанных докладов
(`✍ N`) — он появляется после первой переписки и не занимает футер без
работы. Команда `/session-tidy` показывает счётчики конспектов и докладов
раздельно. Пробник покрывает формат строки, включая отсутствие счётчика при
нуле.

Проверено: `node src/probe.mjs` — 114 passed; живая TUI-сессия — см. ниже.

## Правка: два счётчика

@NikolayXHD: счётчик переписываний реплик нужен отдельно — срывы @NikolayXHD
тоже показатель качества модели («счётчик моей печали»).

Сделано @pi-agent: футер показывает два счётчика — `✍` за переписанные доклады,
😞 за переписанные реплики (знак «счётчика моей печали», @NikolayXHD); каждый
счётчик появляется после своего первого результата и считает только
состоявшиеся замены — растёт именно на проблемных текстах.

Проверено: `node src/probe.mjs` — 124 passed (`formatStatusText`), живая
TUI-сессия — см. выше.
