## Доклад

Виноват, занёс тебе в голову мусорные термины. По делу — вот что это:

У каждого окна tmux можно хранить прицепленные строки (имена начинаются с `@`).
tmux их только хранит и подставляет в шаблоны, никакой своей семантики в них
нет. Наш скрипт кладёт туда три строки, посчитанные из имени окна:

- `@pi_tags` — теги для таба: `" :👀"`
- `@pi_tags_t` — теги для заголовка терминала: `" :👀 "` (с пробелами с двух
  сторон)
- `@pi_name` — имя окна без тегов: `"sb"`

Так сделано потому, что шаблонный язык tmux не умеет ни регулярных выражений,
ни вывести символ `:` — строки считает python, tmux их только подставляет в
заголовок и в таб.

Как назвать файл, который это делает — скажи сам, чтобы я не переименовывал в
третий раз наугад. Варианты, которые не врут про содержимое:

- `pi_title_parts.py` — «части заголовка»
- `pi_window_title.py` — «заголовок окна»
- `pi_tags_hook.py` — «хук, раскладывающий теги»

Сейчас файл называется `pi_title_vars.py` — это моя неудачная попытка,
переименую по твоему слову.

## Переписка

Я привнёс в разговор мусорные термины — извини. Ниже — что это на самом деле.

**Механизм.** Каждое окно tmux хранит прикреплённые строки — имена начинаются с
`@`. tmux не интерпретирует их содержимое: просто подставляет строку в шаблон
заголовка или таба. Семантики в самих строках нет.

**Что скрипт кладёт в эти строки.** Три значения, посчитанных из имени окна:

- `@pi_tags` — теги для таба, например `" :👀"`;
- `@pi_tags_t` — теги для заголовка терминала, например `" :👀 "` (пробелы с
  обеих сторон, потому что шаблон заголовка их не добавляет);
- `@pi_name` — имя окна без тегов, например `"sb"`.

**Почему считает python, а не tmux.** Шаблонный язык tmux не умеет ни
регулярных выражений, ни вывести символ `:`. Поэтому python вычисляет готовые
строки, а tmux лишь подставляет их в заголовок и таб.

**Открытый вопрос: как назвать файл, который это делает.** Скажи сам — я не
хочу переименовывать в третий раз наугад. Варианты, которые не врут о
содержимом:

- `pi_title_parts.py` — «части заголовка»;
- `pi_window_title.py` — «заголовок окна»;
- `pi_tags_hook.py` — «хук, раскладывающий теги».

Сейчас файл называется `pi_title_vars.py` — моя неудачная попытка. Переименую
по твоему слову.
