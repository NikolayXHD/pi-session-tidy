# Проверка переписки на реальных претензиях к изложению

Материал — четыре претензии @NikolayXHD из истории сессий, где он выходил из
себя на плохое изложение докладов агента. Каждый доклад, на который пришлась
претензия, прогнан через запрос переписки: правила из AGENTS.md как контекст
сессии плюс текст задачи из контейнера `reports.md`. Оценка — чинит ли
переписка то, за что досталось.

## Случай 1: категории вместо списков

Претензия (2026-10-12): «перестать делать из ответа кашу — ЧТО ИМЕННО
ДОСТАВЛЯЕТСЯ read tool И НЕ ТРЕБУЕТ ЛОКА, и ОТДЕЛЬНО ЧТО НЕ ПОКРЫВАЕТСЯ И
ТРЕБУЕТ ЛОКА. КОНКРЕТНО, А НЕ В АБСТРАКТНЫХ ОПИСАТЕЛЬНЫХ ПУСТЫХ ФОРМАХ».

Доклад отвечал связными абзацами, обе категории переплетены. Переписка без
правки формулировки разбила текст на абзацы, но оставила связную прозу — явных
списков, которых требовал @NikolayXHD, не было.

После правки текста задачи («категории — явными списками») переписка даёт
заголовки «Чтение через Read tool — схема без лока», «Что схема не покрывает»,
«Где живёт лок» и итог списком из двух пунктов. Требование выполнено.

## Случай 2: дизайн-формулировка кашей

Претензия (2026-10-14): «оба пункта написаны полная каша, ИЗЛАГАЙ ВНЯТНО».
Доклад цитировал дизайн-формулировку одним предложением с вложенными
уточнениями. Переписка разбивает её на три предложения: что запоминается, что
фиксируется отсутствие, что помечает устаревшим. Лечит без правок.

## Случай 3: не расшифрованные термины

Претензия (2026-10-18): «поди угадай что такое tags_t или name или option —
расшифруй термины как есть». Переписка выносит механизм, список строк с
пояснением каждой и причину, почему считает python, в отдельные заголовки с
жирными подзаголовками. Лечит без правок.

## Случай 4: жаргон в одну строку

Претензия (2026-10-19): про фрагмент «pane_pb_state обновляется приложением
через OSC 9;4; tmux сам пересчитывал формат» — «НИХУЯ НИЧЕГО НЕ ПОНЯТНО».
Переписка разворачивает фразу в явное утверждение (приложение шлёт OSC 9;4,
tmux пересчитывает сам, скрипт не участвует), отделяет неточность прошлой
формулировки и вывод с развилкой. Лечит без правок.

## Вывод

Три претензии из четырёх — жаргон, термины, переплетённые мысли — текущая
переписка чинит. Четвёртая вскрыла пробел: содержание-классификацию переписка
оставляла связной прозой, а требование @NikolayXHD было именно в форме — явные
списки. В текст задачи добавлено правило: категории показывать списками с
конкретными именами. Случай 1 перепроверен с правкой — форма требования
выполнена.
